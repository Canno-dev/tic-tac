# tic-tac

Учебный репозиторий по C#. Все проекты открываются через `tic-tac.sln`.

| Папка | Что внутри |
|---|---|
| `TicTac/` | Крестики-нолики (пока заготовка) |
| `Lessons/Chapter1/` | Глава 1 — Hello, World |
| `Lessons/Lesson03/` | Урок 3 — переполнение `int`, точность `double` |
| `Lessons/Lesson04/` | Урок 4 — `char`, `string`, экранирование |

Запуск урока: `dotnet run --project Lessons/Lesson03`
